FCD Settings Modules ⚙️

A lightweight, extensible core framework designed to consolidate various custom WordPress tweaks into a single, beautifully clean admin interface.

Download v1.2.0 View on GitHub

Dismissible Site Notice

A globally deployable site-wide notice with 7 flexible positioning options, built-in SVG icons, and smart local-storage cookies that automatically reset across users when you update the content.

Version history & changes ▼
  • v1.1.17: Added flexible positioning (7 distinct layout options), pre-built and custom color themes, built-in SVG icons, smart dismissal memory, auto-reset on updates, and appearance delay configuration.

Custom Block Ecosystem

Drop in standalone block files to instantly generate toggles in the admin dashboard. Features the flagship ACF-powered Portfolio Gallery block out of the box, complete with touch/drag lightboxes and native theme overrides.

Version history & changes ▼
  • v1.2.0: Added a custom 'Blocks' module to support a series of custom blocks.

Admin Colours Overrides

Seamlessly re-brand the native WordPress "Modern" and "Fresh" dashboard schemes with your agency's primary colors, ensuring a uniform backend aesthetic for all client handoffs.

Version history & changes ▼
  • v1.1.13: Added enable/disable toggle for the admin colour module.
  • v1.0.1: Initial launch of the Admin Colours module.

Editor Styles Mapping

Inject custom CSS directly into the Gutenberg Block Editor to mirror your frontend typography, layouts, and variables without fighting block editor specificity.

Version history & changes ▼
  • v1.1.11: Revised helper text to include `.editor-styles-wrapper` class and native embed instructions.
  • v1.0.1: Added Editor Styles module to map frontend CSS to Gutenberg.

Archive Limits

Precisely override WordPress page limit settings for separate custom post-type archives without breaking globally paginated lists.

Version history & changes ▼
